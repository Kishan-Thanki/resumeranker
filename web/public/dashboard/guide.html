Integration Guide

Authentication

The ResumeRanker API uses API keys for authentication. Visit the API Keys page to retrieve the API key you'll use in your requests.

Remember that your API key is a secret! Do not share it with others or expose it in any client-side code (browsers, apps).

All API requests should include your API key in an Authorization HTTP header as follows:

Authorization: Bearer YOUR_API_KEY

Example Request

curl http://localhost/api/v1/analyze/resume \ --request POST \ --header 'Authorization: Bearer YOUR_API_KEY' \ --form 'resume=@/path/to/resume.pdf' \ --form 'job_description=@/path/to/jd.pdf'
